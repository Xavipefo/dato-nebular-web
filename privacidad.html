Política de privacidad

Última actualización: 19/10/2026

1. Sobre la aplicación

Dato Nebular utiliza la API de YouTube para automatizar la subida de vídeos al canal autorizado por su administrador.

2. Datos utilizados

La aplicación accede al identificador y nombre del canal autorizado y utiliza credenciales OAuth para realizar subidas.

3. Finalidad

Los datos se utilizan para comprobar que los vídeos se suben al canal correcto y para efectuar las publicaciones autorizadas.

4. Almacenamiento

Las credenciales de acceso se almacenan mediante los secretos de GitHub Actions. No se incluyen en el código público.

5. Compartición de datos

La aplicación utiliza los servicios de Google y YouTube para la autenticación y la subida de vídeos. No comercializa los datos obtenidos mediante Google OAuth.

6. Revocación del acceso

El administrador puede revocar el acceso de la aplicación desde las conexiones de su cuenta de Google .

7. Contacto

Para consultas relacionadas con la privacidad, contactar con: datonebular@gmail.com
