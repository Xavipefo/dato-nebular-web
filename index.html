Dato Nebular

Descubre algo nuevo cada día

Dato Nebular es un proyecto de divulgación científica que crea vídeos cortos sobre ciencia, espacio, naturaleza y curiosidades.

Automatización de YouTube

Nuestra aplicación utiliza la API de YouTube para subir vídeos generados por el proyecto al canal autorizado por su administrador.

La aplicación solicita permisos de YouTube únicamente para gestionar las subidas y verificar el canal autorizado.
